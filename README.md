# Anuario 2026 — INSAP

Página web del Anuario 2026 del Área de Investigación en Salud Poblacional (INSAP),
Secretaría de Investigación, Universidad del Hospital Italiano de Buenos Aires.

## Ver la página
Publicada con GitHub Pages en: `https://USUARIO.github.io/anuario-insap-2026/`

## Archivos
- `index.html` — la página completa (un solo archivo: estilos y textos incluidos).

## Cómo actualizar el contenido
1. Corregir los textos en el documento de estructura y contenido.
2. Abrir `index.html` en GitHub → ícono del lápiz (Edit) → hacer el cambio.
3. Botón **Commit changes**. La página se actualiza sola en 1–2 minutos.
